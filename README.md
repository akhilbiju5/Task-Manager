# MEARN STACK TASK-MANAGER

A simple tak manager web application using MERN stack

## TECHNOLOGIES USED

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- Axios
- Mongoose
- bcryptjs

### Authentication

- User Registration
- User Login
- JWT-based authentication
- Logout

### Task Management

- Create tasks
- View tasks
- Update tasks
- Delete tasks

### User Features

- User dashboard
- View assigned tasks
- View task details
- Update task status

## ⚙️ Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/akhilbiju5/Task-Manager.git
```

### 2. Open Project

```bash
cd MERN INTERN
```

### 3.Setup Backend

```bash
cd backend
npm install
```

### 3.1 Start the backend

```bash
npm run server
```

### 4.Setup Frontend

```bash
cd MERN INTERN/frontend/Task-Manager
npm install
```

### 4.1 Start the frontend

```bash
npm run dev
```

### 5 Open the application

```bash
http://localhost:5173/
```
