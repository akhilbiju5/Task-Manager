# MEARN STACK TASK-MANAGER

A simple tak manager web application using MERN stack

## TECHNOLOGIES USED

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- Axios
- Mongoose
- bcryptjs

### Authentication

- User Registration
- User Login
- JWT-based authentication
- Logout

### Task Management

- Create tasks
- View tasks
- Update tasks
- Delete tasks

### User Features

- User dashboard
- View assigned tasks
- View task details
- Update task status
